# React Native Learning Project

This is a **React Native** project bootstrapped using [`@react-native-community/cli`](https://github.com/react-native-community/cli). The project is structured as a **learning + reference app**, where each topic is implemented incrementally and can be used as a real-world starter template.

---

## Getting Started

> **Note**: Make sure you have completed the [Set Up Your Environment](https://reactnative.dev/docs/set-up-your-environment) guide before proceeding.

### Step 1: Start Metro

```sh
# Using npm
npm start

# OR using Yarn
yarn start
```

### Step 2: Build and Run the App

#### Android

```sh
npm run android
# OR
yarn android
```

#### iOS

```sh
bundle install
bundle exec pod install

npm run ios
# OR
yarn ios
```
